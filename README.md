# Jess' Mentoring Knowledge Vault

A comprehensive Obsidian vault designed for personal knowledge management and mentoring resource sharing.

## Purpose

This vault serves as a structured knowledge base for:
- **Personal reference** during career development and technical growth
- **Mentoring conversations** with developers at various stages
- **Resource sharing** with mentees working independently
- **Knowledge repository** for common mentoring scenarios and practical advice

## Content Strategy

- **Practical over theoretical** - Real-world examples and actionable strategies
- **Progressive development** - Structured paths from junior to senior developer topics
- **Holistic growth** - Both technical skills and soft skill development
- **Experience-based** - Lessons learned from actual mentoring relationships

## Best Used With Obsidian

This vault is optimized for [Obsidian](https://obsidian.md/) and includes:

### Theme & Styling
- **Minimal theme** for clean, focused reading
- Custom CSS snippets for enhanced dataview tables
- Progress bars and card layouts for visual organization

### Plugins & Features
- **Dataview** queries for dynamic content tracking
- **Tag system** for categorized navigation
- **Linked references** for connected learning paths
- **TODO tracking** with visual progress indicators

### Installation
1. Download [Obsidian](https://obsidian.md/)
2. Open this folder as a vault in Obsidian
3. Open settings -> community plugins -> enable community plugins (this lets dataview work)

## Vault Structure

```
Mentoring/
├── Career Development/     # Growth planning and progression
├── Technical Growth/       # Skill development and learning
├── Workplace Skills/       # Professional communication and collaboration
├── Industry Knowledge/     # Understanding the tech landscape
├── Specific Challenges/    # Common workplace obstacles
└── Interview Advice/       # Job search and interview preparation
```

## Navigation

- **📋 Mentoring Notes TODO Tracker** - Overview of vault progress
- **Tags** - Browse by topic (`#mentoring`, `#career-development`, etc.)
- **Graph view** - Visualize connections between topics
- **Search** - Find specific advice or examples

## Contributing

This is a personal knowledge vault, but the structure and approach can be adapted for your own mentoring practice. Feel free to fork the organizational system and tailor it to your needs.
